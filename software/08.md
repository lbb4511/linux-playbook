# SSH

SSH（Secure Shell）是一种加密的网络传输协议，用于安全地远程登录 Linux 服务器。

## 远程登录

```sh
ssh 用户名@主机名或IP
ssh -p 端口 用户名@主机名或IP   # 指定端口（默认 22）
ssh-keygen                     # 生成密钥对
ssh-copy-id 用户名@主机名或IP   # 将公钥复制到远程主机，实现免密登录
```

## 配置文件

- 客户端：`~/.ssh/config`
- 服务端：`/etc/ssh/sshd_config`
