# Node.js

Node.js 是基于 V8 引擎的 JavaScript 运行时，主要用于服务端开发和前端构建工具链。

## 安装

```sh
# Arch Linux
pacman -S nodejs npm
```

## 版本管理（nvm）

不同项目需要不同 Node 版本时：

```sh
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

nvm install 20        # 安装指定版本
nvm use 20            # 切换版本
nvm ls                # 查看已安装版本
nvm alias default 20  # 设置默认版本
```

## 包管理

```sh
npm init -y                # 初始化项目
npm install <包名>         # 安装依赖
npm install -g <包名>      # 全局安装
npm uninstall <包名>       # 卸载
npm run <脚本>             # 运行 package.json 中的脚本
```

### pnpm（更快、节省磁盘）

```sh
npm install -g pnpm
pnpm add <包名>
pnpm dev
```

## package.json 要点

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "node --watch index.js",
    "start": "node index.js"
  }
}
```

## 常用框架

- Web：Express、Koa、Fastify、NestJS
- 全栈：Next.js、Nuxt.js
- 工具：Vite、esbuild
- AI：OpenAI SDK、LangChain.js

## 基础示例

```js
// 简单 HTTP 服务器
import http from "node:http";

const server = http.createServer((req, res) => {
  res.end("Hello Linux\n");
});

server.listen(3000);
```
