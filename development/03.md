# Rust

Rust 是 Mozilla 开发的系统级编程语言，以内存安全和高性能著称，适合系统工具、CLI、底层服务开发。

## 安装（rustup）

```sh
# Arch Linux
pacman -S rustup
rustup default stable    # 设置默认工具链
rustc --version          # 编译器版本
cargo --version          # 包管理器版本
```

## Cargo 使用

Cargo 是 Rust 的构建系统和包管理器。

```sh
cargo new my-app         # 新建项目
cargo build              # 构建
cargo build --release    # 发布构建（优化）
cargo run                # 构建并运行
cargo test               # 运行测试
cargo check              # 快速检查（不生成可执行文件）
cargo add <包名>         # 添加依赖
cargo doc --open         # 生成并打开文档
```

## 项目结构

```
my-app/
├── Cargo.toml   # 依赖与元数据
├── Cargo.lock   # 锁定依赖版本
└── src/
    └── main.rs  # 源码入口
```

## 基础语法

```rust
fn main() {
    // 变量默认不可变
    let name = "Linux";
    println!("Hello, {}!", name);

    // 可变变量
    let mut count = 0;
    count += 1;

    // 函数
    let result = add(1, 2);
    println!("{result}");
}

fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

## 常用工具

- `cargo-clippy`：代码检查
- `cargo-fmt`：代码格式化
- `rust-analyzer`：IDE 语言服务
