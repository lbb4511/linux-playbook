# VSCode

Visual Studio Code 是微软出品的轻量级开源编辑器，生态丰富，支持几乎所有语言。

## 安装

```sh
# Arch Linux
pacman -S code
```

## 常用配置

```json
{
  "editor.fontSize": 14,
  "editor.tabSize": 2,
  "files.autoSave": "onFocusChange",
  "terminal.integrated.defaultProfile.linux": "zsh"
}
```

## 常用扩展

- **Python**：Python、Pylance、Jupyter
- **Node.js**：ESLint、Prettier、npm
- **Rust**：rust-analyzer
- **Docker**：Docker 扩展
- **Git**：GitLens、Git History
- **AI**：GitHub Copilot、通义灵码

## 安装扩展

```sh
code --install-extension <扩展ID>      # 命令行安装
code --list-extensions                 # 列出已安装
code .                                # 打开当前目录
```

## 终端集成

内置终端（Ctrl + `），可直接运行：

```sh
npm run dev
cargo run
python main.py
```

## 远程开发

- **Remote-SSH**：连接远程服务器开发
- **Dev Containers**：在容器内开发

## AI 辅助

VSCode 配合 AI 插件实现智能补全：

- GitHub Copilot
- 通义灵码
- Continue（开源）

## 快捷键

| 功能 | 快捷键 |
| ---- | ------ |
| 命令面板 | Ctrl + Shift + P |
| 全局搜索 | Ctrl + Shift + F |
| 打开终端 | Ctrl + ` |
| 快速打开 | Ctrl + P |
| 格式化 | Shift + Alt + F |
