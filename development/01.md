# Python

Python 是解释型、动态类型的编程语言，语法简洁，在 AI、脚本、Web 领域广泛应用。

## 安装

```sh
# Arch Linux
pacman -S python python-pip
```

## 版本管理（pyenv）

同时需要多个 Python 版本时：

```sh
pacman -S pyenv
pyenv install 3.12
pyenv global 3.12        # 设置全局版本
pyenv versions           # 查看已安装版本
```

## 虚拟环境

```sh
python -m venv .venv
source .venv/bin/activate    # 激活
deactivate                   # 退出
```

## 包管理

```sh
pip install <包名>            # 安装
pip uninstall <包名>          # 卸载
pip list                      # 查看已安装
pip freeze > requirements.txt # 导出依赖
pip install -r requirements.txt
```

### uv（更快的包管理器）

```sh
pacman -S uv
uv venv                       # 创建虚拟环境
uv add <包名>                 # 添加依赖
uv run python main.py         # 在环境中运行
```

## 常用框架

- 数据：NumPy、Pandas、Matplotlib

## 基础语法速览

```python
# 变量与类型
name = "Linux"
version = 3.12

# 列表与循环
items = ["git", "docker", "ai"]
for item in items:
    print(item)

# 函数
def greet(name):
    return f"Hello, {name}"

# 字典
config = {"port": 8080, "debug": True}
```
