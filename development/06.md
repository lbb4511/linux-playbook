# opencode

opencode 是终端里的 AI 编程助手（Agent），可理解整个代码仓库，自主执行多步任务：阅读代码、修改文件、运行命令。

## 特点

- 终端原生，无需 IDE
- 可操作完整仓库（搜索、编辑、执行）
- 支持多种模型
- 通过 `AGENTS.md` 了解项目约定

## 安装

```sh
npm install -g opencode-ai
```

## 使用

```sh
opencode                          # 当前目录启动会话
opencode "修复 README 里的错别字"  # 直接下达任务
```

## 常用会话命令

- `/help` 帮助
- `/undo` 撤销上一步修改
- `/models` 切换模型
- `/exit` 退出

## 与项目配合

在仓库根目录编写 `AGENTS.md` 指导 AI：

- 项目结构说明
- 构建/测试/检查命令
- 代码约定与注意事项
