# PyCharm

PyCharm 是 JetBrains 出品的 Python IDE，功能强大，适合 Python 开发，特别是 AI、数据分析场景。

## 安装

```sh
# Arch Linux（社区版）
pacman -S pycharm-community-edition
```

专业版可从 [JetBrains 官网](https://www.jetbrains.com/pycharm/) 下载或使用 `pycharm-professional`（AUR）。

## 启动

```sh
pycharm-community    # 或应用菜单启动
```

## 配置 Python 解释器

项目设置 → Python Interpreter → Add Interpreter：

- 使用项目内虚拟环境（.venv）
- 使用系统 Python
- 使用 Conda/uv 环境

## 常用功能

- 智能补全与代码检查
- 一键运行/调试（F9）
- 内置终端、Git 集成
- Jupyter 集成（专业版）
- 数据库工具（专业版）

## AI 相关配置

PyCharm 支持 AI 插件：

- **GitHub Copilot**：插件市场安装
- **通义灵码**：中文友好
- **JetBrains AI**（官方）

## 快捷键

| 功能 | 快捷键 |
| ---- | ------ |
| 运行 | Ctrl + Shift + F10 |
| 查找 | Ctrl + F |
| 全局搜索 | Ctrl + Shift + F |
| 重构 | Ctrl + Alt + Shift + T |
| 快速修复 | Alt + Enter |
