# Docker Compose

Docker Compose 通过一个 YAML 文件定义和管理多容器应用。

## 安装

```sh
# Arch Linux
pacman -S docker-compose
```

## compose.yaml 示例

```yaml
services:
  web:
    build: .
    ports:
      - "8080:8000"
    depends_on:
      - db
  db:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: myapp
    volumes:
      - db-data:/var/lib/mysql
    ports:
      - "3306:3306"

volumes:
  db-data:
```

## 常用命令

```sh
docker compose up              # 构建并启动
docker compose up -d           # 后台启动
docker compose down            # 停止并删除容器/网络
docker compose down -v         # 同时删除数据卷
docker compose ps              # 查看服务状态
docker compose logs -f <服务>  # 查看日志
docker compose exec <服务> <命令> # 进入服务容器
docker compose build           # 重新构建
docker compose restart <服务>  # 重启服务
docker compose config          # 校验并打印配置
```

## 常用配置项

| 配置项 | 作用 |
| ------ | ---- |
| `image` | 指定镜像 |
| `build` | 指定构建目录 |
| `ports` | 端口映射 |
| `environment` | 环境变量 |
| `env_file` | 从文件加载环境变量 |
| `volumes` | 数据卷挂载 |
| `networks` | 网络 |
| `depends_on` | 服务启动顺序 |
| `restart` | 重启策略（always/unless-stopped） |
| `command` | 覆盖启动命令 |

## 重启策略

```yaml
services:
  web:
    restart: always    # 开机自启，异常退出自动重启
```
