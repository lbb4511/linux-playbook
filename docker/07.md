# 常用容器部署

## MySQL

```sh
docker run -d \
  --name mysql \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -p 3306:3306 \
  -v mysql-data:/var/lib/mysql \
  mysql:8
```

## Redis

```sh
docker run -d \
  --name redis \
  -p 6379:6379 \
  -v redis-data:/data \
  redis:7
```

## PostgreSQL

```sh
docker run -d \
  --name postgres \
  -e POSTGRES_PASSWORD=root123 \
  -e POSTGRES_USER=admin \
  -p 5432:5432 \
  -v pg-data:/var/lib/postgresql/data \
  postgres:16
```

## Nginx

```sh
docker run -d \
  --name nginx \
  -p 80:80 \
  -v ./html:/usr/share/nginx/html \
  -v ./conf/nginx.conf:/etc/nginx/nginx.conf \
  nginx
```

## Node.js 开发环境

```sh
docker run -it --rm -v "$PWD":/app -w /app node:20 bash
```

## Python 开发环境

```sh
docker run -it --rm -v "$PWD":/app -w /app python:3.12 bash
```

## Rust 开发环境

```sh
docker run -it --rm -v "$PWD":/app -w /app rust bash
```

## Docker Compose 一键部署

编写 `compose.yaml` 定义全部服务后：

```sh
docker compose up -d
```
