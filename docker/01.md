# Docker 基本概念

## 镜像（Image）

只读的模板，包含应用运行所需的文件系统、依赖和配置。镜像是分层的，可复用。

## 容器（Container）

镜像的运行实例，是一个隔离的进程，可以启动、停止、删除。多个容器可基于同一镜像。

## 仓库（Registry）

存放镜像的地方，如 Docker Hub、阿里云镜像仓库。

## 关系

镜像 → 容器（运行）→ 仓库（分发）

## 架构组成

- 客户端（docker CLI）
- 守护进程（dockerd）
- 容器运行时（containerd / runc）
- 镜像仓库（Registry）

## 与虚拟机的区别

| 对比项 | 虚拟机 | 容器 |
| ------ | ------ | ---- |
| 操作系统 | 每台一个完整 OS | 共享宿主机内核 |
| 启动速度 | 分钟级 | 秒级 |
| 资源占用 | 高 | 低 |
| 隔离级别 | 强 | 进程级 |

## 常用命令一览

```sh
docker version            # 查看版本
docker info               # 查看系统信息
docker ps                 # 查看运行中的容器
docker images             # 查看镜像
```
