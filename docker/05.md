# Docker 数据卷与网络

## 数据卷（Volume）

容器删除后数据丢失，数据卷用于持久化存储数据。

```sh
docker volume ls                     # 查看卷
docker volume create <卷名>          # 创建卷
docker run -v <卷名>:/data <镜像>    # 挂载卷
docker volume rm <卷名>              # 删除卷
docker volume prune                  # 清理未使用的卷
```

### 绑定挂载（Bind Mount）

将宿主机目录直接挂载到容器：

```sh
docker run -v /宿主机目录:/容器目录 <镜像>
docker run --mount type=bind,src=/宿主机目录,target=/容器目录 <镜像>
```

开发时常用绑定挂载实现代码热更新。

## 网络

### 网络类型

- `bridge`（默认）：容器间通过网桥通信
- `host`：容器直接使用宿主机网络
- `none`：无网络
- `overlay`：跨主机网络（Swarm 使用）

```sh
docker network ls                        # 查看网络
docker network create <网络名>           # 创建网络
docker network inspect <网络名>          # 查看详情
docker network rm <网络名>               # 删除网络
```

### 容器连接网络

```sh
docker run --network <网络名> <镜像>     # 容器加入指定网络
docker network connect <网络名> <容器名> # 已运行容器加入网络
```

同一网络下的容器可通过**容器名**互相访问。

## 端口映射

```sh
docker run -p 8080:80 <镜像>             # 映射到指定端口
docker run -p 8080:80 -p 8443:443 <镜像> # 多个端口
docker run -P <镜像>                     # 随机映射所有 EXPOSE 端口
```

## 示例：容器间通信

```sh
docker network create mynet
docker run -d --network mynet --name db mysql:8
docker run --network mynet --name app -p 8080:80 myapp
# app 容器内可通过 http://db:3306 访问数据库
```
