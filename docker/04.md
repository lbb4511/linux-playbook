# Dockerfile

Dockerfile 是一个文本文件，用指令描述如何构建镜像。

## 常用指令

| 指令 | 作用 |
| ---- | ---- |
| `FROM` | 指定基础镜像（必须是第一条） |
| `RUN` | 构建时执行命令 |
| `COPY` | 复制文件到镜像 |
| `ADD` | 复制文件，支持 URL 和自动解压 |
| `WORKDIR` | 设置工作目录 |
| `ENV` | 设置环境变量 |
| `EXPOSE` | 声明容器监听端口 |
| `CMD` | 容器启动时的默认命令（可被覆盖） |
| `ENTRYPOINT` | 容器启动时的入口命令（不可被覆盖） |

## 示例：Python 应用

```dockerfile
FROM python:3.12-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["python", "app.py"]
```

## 示例：Node 应用

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json .
RUN npm install

COPY . .

EXPOSE 3000

CMD ["npm", "start"]
```

## 示例：多阶段构建（Rust）

```dockerfile
FROM rust:latest AS builder
WORKDIR /app
COPY . .
RUN cargo build --release

FROM debian:bookworm-slim
COPY --from=builder /app/target/release/myapp /usr/local/bin/
CMD ["myapp"]
```

多阶段构建可显著减小最终镜像体积。

## 构建与运行

```sh
docker build -t myapp .       # 构建
docker run -p 8080:8000 myapp # 运行
```

## 构建优化建议

- 将不常变的依赖安装放在前面，充分利用层缓存
- 使用更小的基础镜像（alpine、slim）
- 使用 `.dockerignore` 排除无关文件
- 多阶段构建只保留运行产物
