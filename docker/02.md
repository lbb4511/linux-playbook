# Docker 镜像管理

## 获取镜像

```sh
docker pull <镜像名>                # 拉取镜像
docker pull ubuntu:22.04            # 拉取指定版本
docker pull <仓库>/<镜像>:<标签>     # 从指定仓库拉取
```

常用镜像标签：

- `latest` 最新版
- `alpine` 精简版（体积小）
- `slim` 精简版
- 指定版本号，如 `python:3.12`

## 查看与删除

```sh
docker images                # 查看本地镜像
docker image ls              # 同上
docker rmi <镜像ID或名称>     # 删除镜像
docker image prune           # 清理悬空镜像
docker image prune -a        # 清理所有未使用的镜像
```

## 导入导出

```sh
docker save -o <文件>.tar <镜像名>   # 导出镜像
docker load -i <文件>.tar            # 导入镜像
```

## 构建镜像

```sh
docker build -t <镜像名> <目录>      # 基于 Dockerfile 构建
docker build -t <镜像名> -f Dockerfile.dev .
```

## 国内镜像加速

编辑 `/etc/docker/daemon.json`：

```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn"
  ]
}
```

重启生效：

```sh
systemctl restart docker
```
