# Docker 容器管理

## 创建并运行

```sh
docker run <镜像>                    # 前台运行
docker run -it ubuntu /bin/bash      # 交互式进入容器
docker run -d <镜像>                 # 后台运行（detach）
docker run --name <名称> <镜像>       # 指定容器名
docker run -p 8080:80 <镜像>         # 端口映射：宿主机:容器
docker run -v <目录>:<容器目录> <镜像> # 挂载数据卷
docker run --rm <镜像>               # 退出时自动删除容器
```

## 查看容器

```sh
docker ps                    # 查看运行中的容器
docker ps -a                 # 查看所有容器（含已停止）
docker ps -a --filter name=<名称>
docker stats                 # 查看资源占用
docker logs <容器名>          # 查看日志
docker logs -f <容器名>       # 实时跟踪日志
```

## 生命周期管理

```sh
docker start <容器名>         # 启动已存在的容器
docker stop <容器名>          # 停止
docker restart <容器名>       # 重启
docker rm <容器名>            # 删除（先停止）
docker rm -f <容器名>         # 强制删除运行中的容器
docker rm $(docker ps -aq)   # 删除所有容器
```

## 进入容器

```sh
docker exec -it <容器名> /bin/bash    # 进入容器执行命令
docker exec <容器名> <命令>            # 在容器内执行命令
```

## 容器与宿主机文件互传

```sh
docker cp <容器名>:<容器路径> <宿主机路径>  # 容器→宿主机
docker cp <宿主机路径> <容器名>:<容器路径>  # 宿主机→容器
```

## 容器状态说明

- 已创建（created）
- 运行中（running）
- 已暂停（paused）
- 已停止（exited）
