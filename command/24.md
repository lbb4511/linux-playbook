# ln

ln 命令用于创建链接文件，支持软链接（符号链接）和硬链接。

## 命令格式

`ln [选项] 源文件 目标文件`

## 常用参数

- `-s` 创建软链接（符号链接）
- `-f` 强制创建，覆盖已有文件
- `-i` 覆盖前询问
- `-v` 显示执行过程

## 创建软链接

```sh
ln -s /usr/program/tomcat /opt/tomcat
```

访问 `/opt/tomcat` 即访问 `/usr/program/tomcat`。

## 软链接（符号链接）特点

1. 以路径的形式存在，类似于 Windows 操作系统中的快捷方式
2. 软链接可以跨文件系统，硬链接不可以
3. 软链接可以对一个不存在的文件名进行链接
4. 软链接可以对目录进行链接
5. 源文件删除后，软链接失效

## 硬链接特点

1. 硬链接以文件副本的形式存在，但不占用实际空间（指向同一 inode）
2. 不允许给目录创建硬链接
3. 硬链接只能在同一个文件系统中创建
4. 源文件删除后，硬链接仍可访问内容

## 删除链接

```sh
rm /opt/tomcat    # 删除软链接本身，不影响源文件
```
