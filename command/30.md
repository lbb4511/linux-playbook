# chown

更改文件的所有者或组。命令由单词 change owner 组合而成。

## 命令格式

`chown [选项] 所有者[:组] 文件...`

## 常用参数

- `-R` 递归处理所有子目录和文件
- `-v` 显示执行过程
- `-f` 忽略不存在的文件，不显示错误
- `--reference=参考文件` 将文件的所有者/组设为与参考文件相同

## 常用实例

只改所有者：

```sh
chown tomcat file.txt
```

同时改所有者和组：

```sh
chown tomcat:tomcat file.txt
```

递归修改目录及其下所有文件：

```sh
chown -R tomcat:tomcat /opt/tomcat
```

只改组：

```sh
chown :staff file.txt
```
