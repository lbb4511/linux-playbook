# 用户和用户组

Linux 是多用户多任务操作系统，所有用户记录在 `/etc/passwd`，用户组记录在 `/etc/group`。

## 用户

```sh
useradd <用户名>            # 添加用户
useradd -m <用户名>         # 添加用户并创建家目录
usermod -aG <组> <用户>     # 将用户加入附加组
passwd <用户名>             # 设置密码
userdel -r <用户名>         # 删除用户及其家目录
id <用户名>                 # 查看用户信息
```

## 用户组

```sh
groupadd <组名>             # 添加组
groupdel <组名>             # 删除组
groups <用户名>             # 查看用户所属组
gpasswd -a <用户> <组>      # 将用户加入组
gpasswd -d <用户> <组>      # 将用户移出组
```

## 相关文件

- `/etc/passwd` 用户信息，格式为 `用户名:x:UID:GID:注释:家目录:登录Shell`
- `/etc/shadow` 用户密码信息（仅 root 可读）
- `/etc/group` 用户组信息
- `/etc/sudoers` sudo 权限配置（用 `visudo` 编辑）
