# linux 权限操作

## 查看权限

`ls -l` 输出第一列为文件权限，共 10 个字符：

`drwxr-xr-x`

- 第 1 位：文件类型（`-` 普通文件，`d` 目录，`l` 符号链接）
- 第 2-4 位：属主（u）权限
- 第 5-7 位：属组（g）权限
- 第 8-10 位：其他用户（o）权限

每三位中的字符含义：

- `r` 读（4）
- `w` 写（2）
- `x` 执行（1）
- `-` 无对应权限

## 数字与符号表示

| 数字 | 权限 |
| ---- | ---- |
| 7 | rwx 读+写+执行 |
| 6 | rw- 读+写 |
| 5 | r-x 读+执行 |
| 4 | r-- 只读 |
| 0 | --- 无权限 |

例如 `chmod 751` = `rwxr-x--x`，即 u=rwx, g=rx, o=x。

## 默认权限 umask

新建文件/目录的默认权限由 umask 决定：

```sh
umask           # 查看当前值，如 022
umask 022       # 设置：目录 755，文件 644
```

- 目录默认权限 = 777 - umask
- 文件默认权限 = 666 - umask
