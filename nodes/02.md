# 阅读顺序与导航

本文按分区给出建议阅读顺序，供初学者按章学习。

## 分区与建议顺序

| 顺序 | 分区 | 说明 |
| ---- | ---- | ---- |
| 1 | [文件](/file/) | Linux 目录结构与文件系统，最基础 |
| 2 | [命令](/command/) | 常用命令，建议按侧边栏分类顺序读 |
| 3 | [常用软件](/software/) | 包管理与日常工具 |
| 4 | [开发](/development/) | 语言与 IDE 环境 |

| 9 | [应用](/application/) | 发行版与平台使用（可随需查阅） |

## 命令分区内的阅读顺序

命令分区已按主题分组，建议按以下顺序：

1. **文件目录操作**：ls → cd → pwd → mkdir → rm → cp → mv → touch → cat 等
2. **文件操作**：which → find 系列 → ln
3. **权限**：用户和组 → chmod → chown → chgrp
4. **磁盘存储**：df → du
5. **性能监控**：top → free → vmstat → iostat
6. **网络**：ifconfig → ping → netstat → ss 等
7. **其他**：grep → ps → kill → crontab 等

## 运维分区内的阅读顺序

- 先读 Web/应用服务器（Nginx、Tomcat），掌握站点部署
- 再读数据库（MySQL、Redis、PostgreSQL），掌握数据存储
- 按需深入应用服务器（WebLogic、WebSphere、JBoss）

## 快捷键速查

- 顶部搜索框可全文检索
- 图片可点击放大（zoom-image 插件）
