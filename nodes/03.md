# 笔记与心得

本文记录使用本手册的学习方法与心得模板，供自用或分享。

## 学习方法

1. **先动手**：读完命令立即在终端操作验证
2. **边读边记**：把命令实例复制到自己的笔记，标注用途
3. **按项目学**：如"用 Docker 部署一个 Nginx"串联多个分区知识点
4. **定期回顾**：命令分区随用随查，不必强记

## 笔记模板

```markdown
# <主题>

## 概念
一句话说明是什么、解决什么问题

## 常用命令 / 配置
```sh
命令1  # 用途说明
命令2  # 用途说明
```

## 实例
实际场景 + 完整操作步骤

## 坑与经验
- 易错点
- 注意事项
```

## 记录示例

以 Docker 为例：

```markdown
# Docker 部署 MySQL

## 命令
docker run -d --name mysql -e MYSQL_ROOT_PASSWORD=xxx -p 3306:3306 mysql:8

## 经验
- 记得挂载数据卷，否则容器删除数据丢失
- 首次连接报错先看 docker logs mysql
```

## 建议主题

- 每周一个主题：命令、Docker、Git 分支策略、AI 工具
- 记录实际踩坑，比抄手册更有价值
- 可新建子页面把个人笔记补充进对应分区
