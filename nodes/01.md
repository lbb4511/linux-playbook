# 学习路线总览

本手册按「Linux 基础 → 常用工具 → 开发环境 → 容器与版本控制 → 运维 → AI」的路径组织，由浅入深。

## 一、Linux 基础入门

目标：掌握文件系统、常用命令，能独立操作 Linux 系统。

| 阶段 | 内容 | 分区 |
| ---- | ---- | ---- |
| 1 | 目录结构、文件类型与属性 | [文件](/file/) |
| 2 | 基础命令（ls、cd、cp、rm 等） | [命令 - 文件目录操作](/command/) |
| 3 | 用户与权限（用户、chmod、chown） | [命令 - 权限](/command/) |
| 4 | 磁盘与存储 | [命令 - 磁盘](/command/) |

## 二、常用软件与工具

目标：掌握包管理与日常工具，提高操作效率。

- 包管理：pacman（Arch）、RPM、APT → [常用软件](/software/)
- 终端效率：zsh、tmux → [常用软件](/software/)
- 远程与传输：SSH、FTP、SecureCRT → [常用软件](/software/)

## 三、开发环境

目标：搭建常用语言与 IDE 开发环境。

| 阶段 | 内容 | 分区 |
| ---- | ---- | ---- |
| 1 | Python / Node.js / Rust 基础 | [开发](/development/) |
| 2 | IDE：PyCharm、VSCode、opencode | [开发](/development/) |
| 3 | 版本控制：Git | [Git](/git/) |

## 四、容器化与部署

目标：掌握 Docker 容器化部署。

- 基本概念、镜像、容器 → [Docker](/docker/)
- Dockerfile 与 Compose → [Docker](/docker/)
- 常用容器部署 → [Docker](/docker/)

## 五、运维进阶

目标：掌握 Web 服务器与数据库的部署运维。

- 数据库：MySQL、Redis、PostgreSQL 等 → [运维](/operation-and-maintenance/)
- Web/应用服务器：Nginx、Tomcat、Apache 等 → [运维](/operation-and-maintenance/)

## 六、AI 开发与应用

目标：掌握 AI 工具与本地模型部署，用 AI 辅助开发。

- AI 概述与工具 → [AI](/ai/)
- opencode 命令行助手 → [AI](/ai/)
- 本地大模型部署 → [AI](/ai/)

## 建议

- 按顺序阅读，基础优先；有实战经验后可按需跳转
- 每阶段配合实际操作，笔记区提供 [学习心得参考](03.md)
- 工具类内容随用随查，不必一次读完
