# 本地大模型部署

## Ollama

Ollama 是目前最方便的本地大模型运行工具，一条命令即可运行开源模型。

### 安装

```sh
# Arch Linux
pacman -S ollama
systemctl enable --now ollama
```

### 使用

```sh
ollama pull qwen2.5:7b        # 拉取模型
ollama run qwen2.5:7b         # 交互式运行
ollama list                   # 查看已下载模型
ollama rm <模型名>            # 删除模型
ollama serve                  # 启动服务（默认 11434 端口）
```

### API 调用

Ollama 自带 OpenAI 兼容 API：

```sh
curl http://localhost:11434/api/generate -d '{"model":"qwen2.5:7b","prompt":"你好"}'
```

## llama.cpp

轻量级本地推理框架，支持 CPU 运行量化模型。

```sh
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp && make
./main -m <模型文件> -p "提示词"
```

## 常用开源模型

- `qwen2.5` 通义千问（中文友好）
- `llama3` Meta Llama
- `deepseek-r1` DeepSeek 推理模型
- `gemma2` Google Gemma

## 显存参考

- 7B 模型：约 6-8GB 显存（Q4 量化）
- 13B 模型：约 10-16GB 显存
- 32B 模型：约 20-30GB 显存
- 无独立显卡时可用 CPU 运行小模型（速度较慢）

## 注意事项

- 本地模型能力通常弱于云端大模型
- 量化（Q4/Q8）会损失一定精度但大幅降低显存需求
- 中文场景优先选择 qwen 系列
