# AI 开发概述

## 什么是大模型

大语言模型（LLM）是基于海量文本训练的深度学习模型，能够理解和生成自然语言。代表：

- OpenAI GPT 系列
- Anthropic Claude
- Google Gemini
- 国产：DeepSeek、通义千问、文心一言、Kimi

## 本地 vs 云端

| 对比项 | 云端 API | 本地部署 |
| ------ | -------- | -------- |
| 成本 | 按量付费 | 一次投入（硬件） |
| 隐私 | 数据上传 | 数据本地 |
| 能力 | 模型大、能力强 | 受硬件限制 |
| 离线 | 不可用 | 可用 |
| 使用门槛 | 需注册 API | 需安装配置 |

## 开发方式

1. **API 调用**：通过 HTTP 调用云端模型（OpenAI、DeepSeek、通义等）
2. **本地推理**：用 Ollama、llama.cpp 等在本地运行开源模型
3. **命令行工具**：opencode、aichat 等封装了模型交互
4. **开发框架**：LangChain、LlamaIndex 构建复杂应用

## 常用开源模型

- Qwen 系列（通义千问）
- DeepSeek 系列
- Llama 系列
- Mistral 系列

## 应用场景

- AI 辅助编程（代码生成、补全、review）
- 文档与笔记整理
- 自动化运维脚本
- 问答机器人、RAG 知识库

## 硬件要求

本地部署大模型主要看显存（VRAM）：

- 7B 模型（量化）：约 6-8GB 显存
- 13B 模型（量化）：约 10-16GB 显存
- 70B 模型（量化）：约 40GB+ 显存
