# Python AI 开发环境

Python 是 AI 开发的主流语言，生态最完善。

## 安装

```sh
# Arch Linux
pacman -S python python-pip python-virtualenv
```

## 虚拟环境

每个项目使用独立虚拟环境，隔离依赖版本。

```sh
python -m venv .venv        # 创建虚拟环境
source .venv/bin/activate   # 激活
deactivate                  # 退出
```

## 常用 AI 库

```sh
pip install openai            # OpenAI API 客户端
pip install anthropic         # Anthropic（Claude）客户端
pip install transformers      # Hugging Face 模型库
pip install torch             # PyTorch 深度学习框架
pip install langchain         # 大模型应用开发框架
pip install jupyter           # Jupyter Notebook
pip install requests          # HTTP 请求
```

## 管理依赖

```sh
pip freeze > requirements.txt     # 导出依赖
pip install -r requirements.txt   # 安装依赖
```

## 示例：调用大模型 API

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.deepseek.com",
    api_key="your-api-key",
)

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "用一句话介绍 Linux"}
    ]
)
print(resp.choices[0].message.content)
```

## Jupyter

交互式开发，适合数据处理与模型调试：

```sh
jupyter notebook        # 启动（默认 8888 端口）
jupyter lab             # 新版界面
```

## 开发建议

- 每个项目独立 venv
- 用 `.gitignore` 忽略 `.venv/`
- 涉及密钥放环境变量，不要写进代码
