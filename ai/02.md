# opencode 命令行 AI 助手

opencode 是一个终端里的 AI 编程助手（Agent），可以理解并操作整个代码仓库，执行多步任务、修改文件、运行命令。

## 安装

```sh
# Arch Linux（如已打包）
pacman -S opencode

# 或使用 npm
npm install -g opencode-ai
```

## 基本使用

```sh
opencode                          # 在当前目录启动交互式会话
opencode 某个任务描述             # 直接下达任务
```

在会话中可以：

- 让 AI 阅读代码、定位问题
- 让 AI 修改文件、运行命令
- 通过工具操作仓库（搜索、编辑、执行）
- 在项目内用 `/help` 查看帮助

## 工作目录配置

项目根目录的 `AGENTS.md`（或 `opencode.json`）会被 opencode 读取，用于指导 AI 工作：

- `AGENTS.md`：写清项目结构、命令、约定，让 AI 少犯错
- `opencode.json`：opencode 自身配置（agent、技能、权限、MCP 等）

## 常用会话命令

- `/help` 查看帮助
- `/undo` 撤销 AI 的修改
- `/redo` 重做
- `/models` 切换模型
- `/exit` 退出

## 与 Git 集成

opencode 可操作 git：查看状态、生成提交、执行 push。提交前建议先让 AI 说明改动，确认后再提交。

## 配置

- 项目配置：`opencode.json` / `opencode.jsonc`
- 全局配置：`~/.config/opencode/`
