# Git 安装与配置

## 安装

```sh
# Arch Linux
pacman -S git
```

## 用户配置

首次使用需配置用户名和邮箱，提交时会记录。

```sh
git config --global user.name "你的名字"
git config --global user.email "you@example.com"
```

## 查看配置

```sh
git config --list          # 查看所有配置
git config user.name       # 查看单个配置
git config --global -e     # 编辑全局配置文件
```

配置文件位置：

- 全局：`~/.gitconfig`
- 仓库级：`.git/config`

## 其他常用配置

```sh
git config --global core.editor vim        # 默认编辑器
git config --global init.defaultBranch main # 默认分支名
git config --global alias.co checkout      # 设置别名
git config --global credential.helper store # 记住凭证
```

## 生成 SSH 密钥

```sh
ssh-keygen -t ed25519 -C "you@example.com"
cat ~/.ssh/id_ed25519.pub   # 将公钥添加到 GitHub/Gitee
```

## 测试连接

```sh
ssh -T git@github.com
```
