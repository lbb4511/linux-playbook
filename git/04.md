# Git 分支管理

分支用于并行开发不同功能，互不影响。

## 分支操作

```sh
git branch                       # 查看本地分支
git branch <分支名>              # 创建分支
git branch -a                    # 查看所有分支（含远程）
git branch -d <分支名>           # 删除分支
git switch <分支名>              # 切换分支
git switch -c <分支名>           # 创建并切换分支
git checkout <分支名>            # 切换分支（旧命令）
```

## 合并

```sh
git merge <分支名>               # 合并分支到当前分支
git merge --no-ff <分支名>       # 禁用快进合并，保留合并记录
```

### 合并方式对比

- Fast-forward：目标分支可线性快进，不产生合并提交
- 三路合并：两分支有各自提交，产生合并提交

## 变基

```sh
git rebase <分支名>              # 将当前分支提交移植到目标分支之上
git rebase -i HEAD~3             # 交互式变基，可合并/修改提交
```

> 注意：不要对已推送的公共提交执行 rebase。

## 冲突解决

合并或变基时出现冲突，需手动修改冲突文件后：

```sh
git add <冲突文件>
git commit                       # merge 场景
git rebase --continue            # rebase 场景
```

## 常见分支命名

- `main` / `master`：主分支
- `dev` / `develop`：开发分支
- `feature/xxx`：功能分支
- `fix/xxx`：修复分支
- `release/xxx`：发布分支
