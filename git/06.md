# Git 撤销与回退

## 撤销未暂存的修改

```sh
git checkout -- <文件>     # 丢弃工作区修改（危险）
git restore <文件>         # 等价于上面
```

## 撤销已暂存的修改

```sh
git reset HEAD <文件>      # 取消暂存，保留工作区修改
git restore --staged <文件> # 等价于上面
```

## 回退提交

```sh
git reset --soft HEAD~1    # 回退提交，保留暂存区与工作区
git reset --mixed HEAD~1   # 回退提交，保留工作区（默认）
git reset --hard HEAD~1    # 回退提交，丢弃所有改动（危险）
```

## 反做提交

`git revert` 生成一个新提交来撤销指定提交，不改写历史，适合公共分支。

```sh
git revert <commit>
```

### reset 和 revert 对比

- `reset`：移动 HEAD，改写历史，适合本地未推送的提交
- `revert`：新增反做提交，保留历史，适合已推送的提交

## 丢弃本地所有未推送修改

```sh
git reset --hard HEAD
git clean -fd              # 删除未跟踪的文件和目录
```

## 误删恢复

```sh
git reflog                 # 查看所有操作记录
git reset --hard <commit>  # 恢复到记录中的提交
```

`reflog` 记录了 HEAD 的所有移动，是误操作后的最后防线。
