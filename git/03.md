# Git 基础操作

## 初始化与克隆

```sh
git init <目录名>        # 初始化仓库
git clone <仓库地址>      # 克隆远程仓库
git clone <地址> <目录>   # 克隆到指定目录
```

## 提交流程

```sh
git status               # 查看工作区状态
git add <文件>           # 添加文件到暂存区
git add .                # 添加所有改动
git commit -m "提交说明"  # 提交
git commit -am "说明"     # 跳过暂存直接提交已跟踪文件
```

## 查看状态与差异

```sh
git status               # 工作区状态
git diff                 # 工作区与暂存区差异
git diff --staged        # 暂存区与仓库差异
git log                  # 提交历史
git log --oneline        # 简洁历史
git log --graph          # 图形化历史
```

## 查看提交

```sh
git show <commit>        # 查看某次提交详情
git show HEAD            # 查看最新提交
```

## 忽略文件

在 `.gitignore` 中声明不需要跟踪的文件：

```gitignore
*.log
node_modules/
build/
dist/
```

## 文件操作

```sh
git mv <旧> <新>         # 移动/重命名文件
git rm <文件>            # 删除文件
```
