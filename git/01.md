# Git 基本概念

## 版本控制系统

版本控制系统（Version Control System）用于记录文件内容的变化，方便回溯、协作。

- 集中式（CVCS）：SVN、CVS，代码集中存储在服务器
- 分布式（DVCS）：Git、Mercurial，每个本地仓库都是完整的备份

## 三个工作区域

- 工作区（Working Directory）：本地编辑文件的区域
- 暂存区（Index/Staging Area）：`git add` 后存放待提交内容
- 仓库（Repository）：`git commit` 后提交内容所在

## 对象模型

- Blob：文件内容
- Tree：目录结构
- Commit：一次提交快照
- Tag：指向某个提交的标签

## 常用术语

- 提交（commit）
- 分支（branch）
- 远程（remote）
- 追踪（tracking）
- 冲突（conflict）
- 合并（merge）
