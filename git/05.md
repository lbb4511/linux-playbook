# Git 远程仓库

远程仓库（remote）指托管在服务器上的 Git 仓库，常见的有 GitHub、GitLab、Gitee。

## 关联远程

```sh
git remote add origin <仓库地址>   # 添加远程仓库
git remote -v                     # 查看远程仓库
git remote remove <名称>          # 删除远程
git remote set-url origin <新地址> # 修改远程地址
```

## 拉取与推送

```sh
git clone <地址>                  # 克隆（自动关联 origin）
git pull                          # 拉取并合并
git fetch                         # 只拉取不合并
git push                          # 推送当前分支
git push origin <分支>            # 推送指定分支
git push --tags                   # 推送所有标签
```

### pull 和 fetch 的区别

- `git fetch`：仅下载远程更新，不改变工作区
- `git pull` = `git fetch` + `git merge`

## 上游分支（tracking）

```sh
git push -u origin main           # 首次推送并设置上游
git branch -vv                    # 查看分支跟踪关系
```

## 标签

```sh
git tag                           # 查看标签
git tag <标签名>                  # 创建轻量标签
git tag -a v1.0 -m "说明"         # 创建附注标签
git tag -d <标签名>               # 删除本地标签
git push origin <标签名>          # 推送标签
git push origin --tags            # 推送所有标签
```

## 常见远程地址格式

- HTTPS：`https://github.com/用户/仓库.git`
- SSH：`git@github.com:用户/仓库.git`
