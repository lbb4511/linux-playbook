# Git 常用技巧

## 暂存工作区

需要切换分支但不想提交当前修改时：

```sh
git stash                  # 暂存当前修改
git stash list             # 查看暂存列表
git stash pop              # 恢复最近一次暂存
git stash drop             # 删除暂存
```

## 多工作区（worktree）

`git worktree` 可同时检出多个分支到不同目录，适合并行开发不同功能、快速切换上下文。

```sh
git worktree list                        # 查看所有工作区
git worktree add <目录> <分支>           # 新建分支并检出到新目录
git worktree add -b <新分支> <目录>      # 创建并检出到新目录
git worktree add <目录> --detach         # 检出到任意提交（不关联分支）
git worktree remove <目录>               # 删除工作区
git worktree prune                       # 清理失效的工作区记录
```

### 典型用法

```sh
git worktree add ../linux-playbook-fix fix/xxx
cd ../linux-playbook-fix
# 在 fix/xxx 分支上修改，不影响主工作区的 main
```

> 同一分支只能在同一个仓库中被检出一个工作区。删除前需先退出该目录或关闭其中的进程。

## 挑选提交

将其他分支的某个提交应用到当前分支：

```sh
git cherry-pick <commit>
```

## 查看某文件的历史

```sh
git log -- <文件>          # 文件的提交历史
git blame <文件>           # 每行由谁在哪个提交修改
```

## 搜索

```sh
git grep <关键词>          # 在当前提交中搜索
git log --grep=<关键词>    # 按提交信息搜索
```

## 修改提交信息

```sh
git commit --amend -m "新信息"   # 修改最近一次提交信息
```

> 已推送的提交不要 amend。

## 关联本仓库说明

本仓库（linux-playbook）相关操作示例：

```sh
git status
git add .
git commit -m "说明"
git push
```
